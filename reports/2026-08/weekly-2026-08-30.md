本周 Agent 工程化从“能跑”加速迈向“能生产”的深水区。继 Stripe Kai、SRE 智能体之后，LangChain 彻底重写自家文档问答机器人，明确提出 15 秒端到端响应硬约束，并为此引入 Deep Agents 与子图架构——子图并行执行压低了延迟，同时每个子图强绑定来源引用，解决了复杂查询下传统 RAG 遗漏与不可信的问题。这标志着 Deep Agents 范式已从快速原型验证进入内部生产系统的自噬式迭代：用自己造的框架解决自己的真实产品瓶颈。与此同时，实时自我改进能力集中爆发，PILOT 通过监督者‑工作者分离与实时转向，让长周期代理在任务中途就能纠错并固化技能，在线学习闭环大幅降低无效探索，这是对离线事后改进模式的根本性升级。此外，TTPO 等测试时优化方法绕过真实标签依赖，直接提升推理性能，说明“不靠标注数据也能持续提升模型表现”正在成为一条可落地的技术路线。

## 面试视角

第一，谈生产级代理的架构取舍时，可以引用 LangChain 的 15 秒硬约束案例：延迟要求直接决定了子图并行化与 Deep Agents 调度粒度，这说明在选型时不能只追求智能，而要先定义 SLO，再反推架构，做到“智能与可控的平衡”。第二，面对“如何降低长周期 Agent 的 API 成本”时，可结合 PILOT 的实时转向与自我进化：监督者实时干预避免无效执行，输出 token 量下降 40% 以上，每百万 token 成功评估次数翻倍，这是通过架构优化而非单纯换模型来实现降本增效的典型论据。第三，在讨论 Agent 数据策略时，可以提及 What Makes Good Agentic Data? 的 ACE 原则，以及 TTPO 无需标签的测试时优化，说明即使缺乏高质量标注，也能通过合理的伪标签机制与在线学习来构建训练和评估数据，这对初创团队或冷启动场景下的数据工程有直接指导意义。
