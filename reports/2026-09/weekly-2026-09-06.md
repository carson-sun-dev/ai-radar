### 2. LatentPress: Context Compression Beyond Text and Vision

这是一项关于上下文压缩的新研究，提出了一种名为 LatentPress 的方法。它的核心思路是：不再把压缩后的上下文保存为人类可读的文本或需要解码的图像，而是直接写成一种“连续记忆令牌”（continuous memory tokens），让下游的语言模型通过其输入嵌入接口直接读取，推理时完全不需要重建文本。

> 评分 8/10 · 连续记忆token压缩上下文，无需文本重建，对长上下文工程和推理成本优化有突破性价值
> 来源：<https://huggingface.co/papers/2609.01507> · 发布 2026-09-01

### 3. HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?

HarnessDev 是一个将评估重心从任务输出转移到可运行执行基础设施的基准，它考察大模型能否自行构建并演化自身的智能体执行框架。该基准包含两个阶段：创建阶段要求模型从最小种子和少量示例出发构建完整执行系统，演化阶段则基于下游执行反馈迭代改进自建框架，以提升基准性能。研究发现，在代码、搜索与研究领域，生成框架仍明显落后于成熟的人工参考实现，但在写作和机器学习实验任务上已能匹敌甚至超越参考框架，同时执行成本差异显著。这项工作值得关注，因…

### 4. CAST: Critique-Aware Supervision for Training Reliable Long-Horizon Tool-Calling Agents

这是一篇关于训练可靠长周期工具调用智能体的新方法 CAST 的论文。它提出了一种“批判感知监督”框架，专门用来提升大语言模型智能体在需要多步操作、状态持续变化的复杂任务中的可靠性。

> 评分 8/10 · 长周期工具调用agent的批评感知监督，直接解决agent可靠性这一生产核心问题，方法有代码可复现。

## 本周趋势

本周走向集中在三个方向：一是上下文压缩从“人可读”转向“机可读”的软令牌表示，LatentPress 用冻结解码器+轻量写者实现 4-16 倍压缩，且在部分场景下质量反超原始上下文，暗示压缩本身可能具备信息聚焦的“去噪”效应；二是长周期智能体的可靠性训练从稀疏的最终成败信号，细化为动作级的批判监督，CAST 通过批判模型与策略模型分离的设计，将跨域任务稳定成功率提升近 10 个百分点，形成“审查-执行”解耦的闭环优化范式；三是工具调用协议走向标准化与工程适配，MCP 在 LangChain 中落地为无状态集成，结合 LangGraph 中断机制处理 elicitation，同时缓存工具列表以降低延迟，直接回应了生产环境中工具生态扩展和状态管理的痛点。此外，HarnessDev 和 WHALE 还反映出智能体执行框架本身正在成为可优化、可演进的对象，而不仅是静态的依赖层。

## 面试视角

1. 谈 LatentPress 的软令牌压缩时，可以连接应用工程中长对话历史或海量文档检索的成本优化决策：在模型选型上，冻结主干、仅训练轻量写者能大幅降低适配成本，且写操作 43ms、读加速 5-9 倍的数据可作为架构设计中延迟预算的量化依据，尤其适合需在端侧或低延迟场景下处理的 RAG 系统。
2. 谈 CAST 的批判感知训练时，可以类比为给智能体引入独立审计模块：在架构层面，将安全审查逻辑与执行逻辑分离，不仅便于合规审查，还能在金融、客服等高风险场景中减少不可逆操作失误，面试时可用此说明如何从模型训练角度提升系统的稳定性与可信度。
3. 谈 MCP 在 LangChain 中的无状态适配时，可结合 LangGraph 中断机制阐述人机协同工作流的设计：当 Agent 需要用户确认或补充信息时，不是陷入复杂的回调，而是通过图中断暂停执行、等待外部响应，这直接对应 production 中审批流、表单填写等场景的架构选型，同时工具列表缓存也体现了对性能细节的工程化考量，适合在讨论 Agent 与外部系统集成方案时展示对前沿协议和落地实践的跟进。
